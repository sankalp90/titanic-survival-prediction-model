🚢 Titanic Survival Prediction

A Machine Learning web application that predicts whether a passenger would have survived the Titanic disaster based on passenger details such as age, gender, passenger class, fare, and family information.

Built using Python, Scikit-learn, Pandas, and Streamlit, this project demonstrates an end-to-end machine learning workflow, from model training to interactive web application deployment.

📌 Project Overview

The Titanic Survival Prediction project uses historical passenger data from the Titanic disaster to build a machine learning model capable of predicting passenger survival.

Users can enter passenger information through an interactive Streamlit interface and receive a survival prediction generated by the trained machine learning model.

✨ Features
Predicts passenger survival using a trained Machine Learning model.
Interactive and user-friendly Streamlit interface.
Takes passenger details as input.
Uses a pre-trained model saved with Joblib.
Fast predictions without retraining the model.
Easy deployment using Render or Streamlit Community Cloud.

🧠 Machine Learning Workflow

The project follows a typical machine learning pipeline:

Data Collection: Obtain the Titanic passenger dataset.
Data Preprocessing: Handle missing values and prepare features.
Feature Engineering: Select and transform relevant passenger attributes.
Model Training: Train a machine learning classification model.
Model Serialization: Save the trained model using Joblib.
Prediction: Load the saved model and generate predictions through Streamlit.
📊 Input Features

The application uses passenger information to generate survival predictions.

Examples of relevant Titanic dataset features include:

Passenger Class (Pclass)
Sex
Age
Number of Siblings/Spouses (SibSp)
Number of Parents/Children (Parch)
Passenger Fare
Embarkation Port (Embarked)

The exact input features depend on the model implemented in the project.
